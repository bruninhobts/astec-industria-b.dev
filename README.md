## 🇧🇷 Português

> **Portal Corporativo e Catálogo de Peças com Solicitação de Orçamento (RFQ)**

Site de catálogo institucional focado em captação de orçamentos (leads) industriais e exposição estruturada de maquinários.

### 🚀 Principais Funcionalidades
- **Catálogo de Maquinários**: Filtros e especificações estruturadas para maquinário industrial de grande porte.
- **Solicitação de Orçamentos (RFQ)**: Permite ao usuário solicitar cotações de várias peças de uma só vez.
- **Desempenho e SEO**: Carregamento ultra rápido e excelente indexação orgânica no Google Search.
- **Painel Administrativo**: Gestor simplificado para inclusão de novos produtos, manuais e listagem de contatos.

### 🛠️ Tecnologias
- **Base**: HTML5, Vanilla CSS (estética glassmorphism), JavaScript nativo, PHP, MySQL.

## 🇺🇸 English

> **Heavy Machinery Web Catalog & RFQ Quoting Engine**

High-performance corporate catalog designed for heavy machinery manufacturers to capture quotes.

### 🚀 Key Features
- **Machinery Catalog**: Deep categorizing system for industrial products and machinery sheets.
- **RFQ Quoting Engine**: Simple quote basket where users can request prices for multiple items.
- **High Performance & SEO**: Fast page loads optimized for low-bandwidth factory locations.
- **Admin Panel**: Lightweight dashboard to upload catalogs, technical specs, and track quote leads.

### 🛠️ Tech Stack
- **Stack**: HTML5, Vanilla CSS (modern glassmorphism), JavaScript, PHP, MySQL.
